# Results Index

`metrics.md` and `experiment-summary.md` are the project-level overview files. Other outputs are grouped by analysis stage.

## 01_supplementary

Results reproduced directly from the paper and source-study supplementary workbooks.

- Gene and stress-response counts
- Salt and drought expression matrices and heatmaps
- Promoter cis-element summary and figure

## 02_genome

Results derived from the Draper V1.0 genome and GFF annotation.

- Promoter extraction coordinates
- Per-copy gene structure table
- Exon-count summary and figure

## 03_domain_screen

Results from bZIP homology screening and Pfam domain confirmation.

- Paper gene-to-protein mapping
- Homology candidates
- Pfam domain hits
- Additional candidate analysis

## 04_phylogeny

Results from the VcbZIP and Arabidopsis bZIP comparison.

- Arabidopsis reference mapping
- Protein alignment
- UPGMA tree
- Nearest Arabidopsis reference table

## 05_expression

Results that verify the bZIP paper's stress-response tables against the original studies.

- Drought FPKM verification
- Salt and ABA membership verification
